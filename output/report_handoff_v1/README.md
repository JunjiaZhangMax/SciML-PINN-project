# 阶段结果交接 v1

本包给报告撰写者汇总三组已完成实验。由保存的最终 metrics.json、history.csv 和 config.json 整理。各组均为 seed 0 单次结果，适合写作阶段性实验与讨论。后续优化、重复实验及最终选型仍待完成。

## 先看什么

- results_percent.csv：三组汇总，字段名含 percent 的数值已经乘以 100。
- 各实验文件夹中的 *_history.png：训练损失和反问题参数曲线。
- inverse_wake_comparison.html：浏览器直接打开，三列依次为真值、5,000 点模型、100 点模型，三行依次为 u、v、去均值压力。共用时间轴；默认真值范围的色标会用粉色和金色标记超范围值，也可切换到全部模型范围。
- forward_comparison.html：全时间窗正问题预测与真值的同步动画；forward_comparison.png 是静态预览。
- forward_baseline/diagnostics/：逐时刻误差、振幅诊断及对应图表。

## 问题背景与共同设定

数据来自 cylinder_nektar_wake.mat，表示圆柱下游窗口 x∈[1,8]、y∈[−2,2]，时间 t∈[0,19.9]。坐标、时间与物理量遵循原数据的无量纲约定。

网络输入 (x,y,t)，输出流函数 ψ 与压力 p；速度为 u=ψ_y、v=−ψ_x。网络为 8 个隐藏层，每层 20 个神经元，tanh，float64。动量方程包含对流系数 λ₁ 和黏性系数 λ₂，参考值分别为 1 和 0.01。

每个实验均保留独立测试样本。压力评估时，对预测与参考值分别按每个测试时刻减去空间均值。HTML 展示全空间场，含训练位置；正式误差取自 metrics.json 的独立测试点。

## A. 反问题成功基准

目录 inverse_adam5k_lbfgs50k_seed0。5,000 个时空速度观测，零附加噪声；PDE 残差在同一批观测坐标计算。Adam 5,000 步后接 L-BFGS 45,000 次。目录保留早先 50,000 次预算的名称，实际预算以配置与 metrics.json 为准。

最终 λ₁=0.9998595，λ₂=0.01006541，相对误差分别为 0.0140% 与 0.6541%。10 万个测试点上，u、v、去均值压力的相对 L2 误差分别为 0.2616%、1.0608%、1.8784%。

stage_comparison.json 保存 Adam 结束与最终结果。Adam 5,000 步时 λ₁、λ₂ 误差约为 92.8%、80.9%，接 L-BFGS 后识别明显改善。本实验比较的是同一条训练轨迹的不同阶段；未做相同额外计算预算的 Adam 对照，因此不能仅凭这组断言 L-BFGS 在所有情况下更优。

训练经历多次断点恢复，L-BFGS 曲率历史曾重建。日志累计耗时受运行条件影响，作硬件效率比较前需要核对有效计算时间。

## B. 稀疏带噪声反问题失败案例

目录 inverse_n100_noise05_seed0。100 个时空速度观测、5% 噪声、5,000 个固定无标签 PDE 配点；Adam 5,000 步加 L-BFGS 45,000 次。

噪声逐速度分量生成，u_obs=u+0.05·std(u_train)·ε，v 同理；ε 为标准正态变量，标准差取无噪声训练观测。

最终 λ₁≈−1.99×10⁻⁵，λ₂≈−6.54×10⁻⁷，两者的相对误差都约为 100%，黏性系数还略为负值。10 万个测试点上，u、v、去均值压力的误差分别为 96.83%、176.62%、99.60%。

训练损失很低仍然出现参数识别与场重建失败，是本案例的主要观察。单一 seed 的结果不能证明所有 N=100 的实验都会失败。与 A 同时改变了观测数、噪声及 PDE 配点方式，尚不能区分各因素贡献。两参数趋零是否意味着近似稳态或其他退化机制，需要额外导数诊断。

## C. 正问题全时间窗基线

目录 forward_baseline。固定 λ₁=1、λ₂=0.01，使用真实 t=0 初始速度和矩形窗口四边的边界速度，内部配点仅施加 PDE 残差。配置中的 n_observations 和 collocation 是通用旧字段，正问题实际由 prepare_forward_data 构造初值、边界和内部配点。

Adam 50,000 步，无 L-BFGS。在 99,500 个测试点上，u、v、去均值压力误差分别为 14.12%、53.91%、64.71%。参数是已知常数，因此无需报告“参数识别零误差”。

动画和 diagnostics 展示后期尾流重建变差的现象，用作后续短时间滑动窗口研究的动机。此组与反问题使用的信息和优化器不同，不能从其误差较大直接得出正问题普遍更难。

## 正文建议与局限

正文可以各选一张有解释力的图：A 的参数收敛图、A/B/真值的同一时刻场对照、C 的逐时刻诊断图。动画适合展示或补充材料，报告用截图时注明物理时刻、物理量、共用色标及超范围颜色。

表格应包含三组全部结果。不要只保留成功案例，也不要把单次结果写成均值±标准差。目前的分析已用于规划后续实验，应标为探索性 pilot；正式结论需要在固定设置下补充重复性检验。

本包侧重写报告所需材料。训练权重、原数据和大体积预测数组仍保存在本机项目的 runs 与 data 目录；各图及指标的生成来源可由随附配置、历史和动画 source.json 追溯。
