# 正问题实验：沿时间推进的重叠窗口 PINN

研究问题：在固定 λ₁=1、λ₂=0.01、只给真实初始速度和已知边界速度时，将优化限制在短时间段，能否减轻后半程尾流的振幅衰减与相位漂移？

## 窗口和预算

按数据集的无量纲时间计，第 k 窗起点为 2k（k=0,…,8），终点为 min(2k+4,19.9)，两端均含。依次为 [0,4]、[2,6]、[4,8]、[6,10]、[8,12]、[10,14]、[12,16]、[14,18]、[16,19.9]。每窗 Adam 5,000 步，总上限 45,000 步。不同窗口顺序训练；每个窗口独立保存自己的最终模型。

## 第一版怎么训练

1. 第一窗用 t=0 的真实速度作初值。每窗只使用窗内已知边界速度、无标签 PDE 配点和原有压力规范项。沿用基线网络、损失权重和学习率，每窗从训练池抽 5,000 个 PDE 配点。预先固定全时间域测试索引，所有窗口共享并排除这些索引。比较时记录各窗的边界点、配点数量和耗时。
2. 后续窗复制前一窗的网络权重，并保持相同的全域输入归一化；重置 Adam 的动量。用冻结的前一窗在新窗起点预测速度 u,v，一次计算并保存为新初值。例如第二窗取前一模型在 t=2 的预测。计算流函数导数时启用自动微分，再 detach 速度标签。t>0 的内部真实速度只在评估时读取。
3. 第一版只匹配起点速度；重叠段继续用边界和 PDE 训练。这样模型能修正前一窗的误差。首两窗结束后先看 t=2 的交接误差以及 [2,4] 上两模型速度差。如果明显脱节，再把“重叠段少量点上的弱速度一致性损失”作为单独对照，避免把前一窗的错误锁死。压力沿用同一规范，不用压力真值交接。
4. 第一版拼接使用前一窗预测直到其右端点，再用下一窗预测新时间段。这样第二窗经过 [2,4] 的适应段之后才负责 t>4 的输出。保留重叠区两份原始预测，在每个切换点报告两模型同一时刻的速度 RMS 差；不做视觉平滑。

## 怎么判断值不值得继续

先跑前两窗，共 10,000 步。看边界和初值是否拟合、同一位置的横向速度 v(t) 能否跟上前几次振荡、切换处是否跳变。若首窗本身就学不出振荡，先定位首窗误差，避免连续传播八次。通过后沿用两个模型继续后七窗。

对照优先用同网络、同边界定义、同测试集的全时间窗 Adam 45,000 步；已有 50,000 步基线可先作参考，但报告需注明预算不同。记录 GPU 实际耗时，窗口重采样也会改变训练所覆盖的独特点数。主要看后半程 (t≥10) 测试集的 u、v 与逐时刻去空间均值的压力相对 L2，并分别报告全程指标。在预先选定的下游位置叠画真值、全窗、滑窗 v(t)，比较后半程振幅与波峰到达时间；按同一规则展示全部切换点。

若滑窗的后期误差更小、振幅更接近真值且交接跳变可接受，再补随机种子。若振幅好转而相位持续漂移，应分别报告；窗口缩短了单次拟合跨度，无法消除错误初值沿时间传播的影响。
