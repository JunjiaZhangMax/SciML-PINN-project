# 小组实施清单

## 第 1 周：实现与检查

- [ ] 确定实现、实验、分析三位负责人，共同审阅公式。
- [ ] 在 Brightspace 核对实际截止日、篇幅与提交渠道。
- [ ] 下载数据、核验轴顺序和范围、查看真值快照。
- [ ] 实现网络、速度、导数与残差，通过可解析函数测试。
- [ ] 实现 loss，通过参数梯度检查。
- [ ] 打通短训练、日志、checkpoint、恢复与评估。
- [ ] 已知系数检查，再做无噪声反问题，记录基线审阅标准。
- [ ] 测耗时、估算 25 次预算，冻结正式配置。

## 第 2–3 周：实验

- [ ] 完成 reference 的 6 次运行，核验基线。
- [ ] 完成 18 次 sensitivity，保留每一次失败记录。
- [ ] 检查嵌套抽样、共享配点/测试集、噪声配对。
- [ ] 汇总均值、样本 SD、单次结果、耗时和失败数。
- [ ] 完成噪声图、稀疏图、场图，冻结核心结果。

## 第 4–5 周：分析与交付

- [ ] 解释参数、速度和压力的误差差异与失败机制。
- [ ] 完成算法伪代码、报告与局限性分析。
- [ ] 所有数字和图能追溯至配置、日志与索引。
- [ ] 准备 slides，安排全员参与并彩排。
- [ ] 从干净环境验证 README，核对课程交付项。

只有四周时合并最后两周，优先保留三次重复、失败分析与完整交付。
